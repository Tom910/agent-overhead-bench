What the interval means

Exploratory 95% percentile task-cluster bootstrap, 10,000 deterministic resamples. Each task and all its repetitions move together; harnesses are paired by task, not by random seed. Marginal intervals are not corrected for multiple comparisons or winner selection. 8 task clusters provide limited evidence about other coding tasks. These intervals do not remove configuration, environment or verifier confounding.

A narrow interval does not prove equal performance. “Best = 100%” is an observed relative index. Corrected audit results are separate and do not enter these intervals.

How the comparison works

Model deepseek/deepseek-v4.1-flash-1017. 5 harnesses, 8 tasks; repetition counts are shown for each task. Routing, configuration and collection conditions are specific to the selected population and retained in its evidence. Pass rate is native verifier passes divided by all selected attempts. A verification failure alone does not distinguish a task failure from verifier infrastructure failure.

Lower token usage alone does not establish better task performance. Relative scores use all measured harness versions within the selected population and task scope, even when some are hidden. A ≥ cost is a known lower bound; incomplete metrics are excluded from relative scoring.

Token-based reference pricing

$0.15 per million uncached input tokens, $0.003 per million cached input tokens, and $0.6 per million output tokens. Reference estimates, not billing. Reference book: deepseek-v41-1017-reference-2026-10-18. Original books: deepseek-v41-1017-reference-2026-10-18. Exact request counters feed the existing report calculation. These are reference estimates, not actual billing.

Passes and failures both contribute to costs and token/cache summaries. Cost averages weight tasks equally. Filtering to one task shows its average across repetitions and sum across all selected runs.

Limitations & recovery audit

This is a completion-selected descriptive snapshot across two original tool cohorts. It is not the frozen v1 dataset. The selected tasks do not establish broad capability estimates; repeated runs do not create independent tasks. Recorded image, environment and collection differences limit interpretation; inspect the selected population’s evidence before treating it as a controlled comparison. Detailed reports retain environment identities.

Non-model time includes unobserved tools and harness work. See the bound collection diagnostics for this population. No separate corrected-verifier audit is bound.
