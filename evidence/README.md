# Evidence index

This directory is reserved for dated, reproducible evidence about the v1
release. It intentionally contains no provider keys, captured request bodies,
task reference solutions, screenshots, or publication claims.

`index.json` is a pending ledger. Human release work may add an entry only after
the corresponding artifact exists and its URL, access date, and local archive
are recorded. The official dataset is produced by `scripts/s7-freeze.sh` and is
not copied into this directory. The 2026-09-14 campaign files are a checksummed
snapshot of selected outcomes, not that freeze.
