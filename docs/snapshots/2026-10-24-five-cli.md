each CLI. All use the pinned 1017 model and DeepSeek provider routing. This is a
descriptive snapshot across two tool cohorts.

## What the data shows

Pi and Codex have the same observed pass count. Pi has 19.23% lower mean reference
cost and 11.75% shorter median time in this sample. Their pass-rate difference is
inconclusive: the exploratory task-cluster interval is −25 to +31.25 percentage
points. Eight tasks and two repetitions do not establish equal reliability or a
universal best CLI.

Recorded model-request intervals account for a median 79.2%–83.5% of elapsed run
time across the five CLIs. Median request counts are 252.5 for Cline, 64 for Codex,
98.5 for Hermes, 57 for Pi and 83 for Qwen. Request volume is a useful target for
further analysis. Tool visibility is partial; remaining time includes unobserved
tool work and cannot be assigned entirely to harness overhead.

## Cline's commit obligation

Fresh independent verification checked all 16 Cline native grades and their
source hashes. Every run failed `workflow.changes-committed`. In exactly eight
runs, that was the only failed assertion: every code assertion passed. The
other eight runs also had failed code assertions.

**The native score remains 0/16.** Completing the required workflow is part of
the native task contract. These records establish the failed commit check; they
do not establish why it failed. This score alone does not mean that all 16
patches failed their code tests.

The [supplemental assertion proof](2026-10-24-cline-workflow.json) contains all 16
original native manifest/reward JSON records, exact hashes and failed assertion
identifiers. Its manifest hashes bind to the approved
[native-evidence file](../../evidence/linux-results-2026-10-24/native-evidence.json).
It contains no model messages, raw logs, code patches or credentials. Original
grades and all six immutable snapshot source files are unchanged.

## Comparison with the historical snapshot

The historical snapshot recorded 105/200 passes (52.5%); this snapshot records
44/80 (55%). Observed rates changed as follows: Cline 45%→0%, Codex 50%→81.25%,
Hermes 47.5%→56.25%, Pi 57.5%→81.25%, and Qwen 62.5%→56.25%.

The model version, repetition count, environment/verifier details and collection
periods differ. These observations do not establish a causal improvement from
the model update. The old snapshot has five repetitions per task; this one has
two, which gives less evidence about repeatability.

[Historical 200-trial evidence](../../evidence/linux-results-2026-09-19-r1/README.md)
remains available. The supplemental workflow check is not a regrade of either
snapshot and is not a general capability ranking.

## Scope and retained attempts

The 80 selected outcomes contain 44 native passes and 36 failures. There were
83 observed paid primary attempts and 52 prerequisites. Three extra primary
attempts are retained separately: the original Pi interruption, Cline's
10,800.372-second timeout, and Cline's budget interruption. Their known prefix
reference estimates total $2.284068444; their full costs remain unknown. The
prerequisite known reference subtotal is $5.283952392, with unknown full cost.
Reserves are not charges. Completion selection excludes these incomplete
attempts from the selected 80 columns.

Two original cohorts and six collection windows are recorded. Two ledger ends
remain open. The original 32 Pi/Qwen facts are exact; the extension preserves
41 imports and seven fresh outcomes. Three partial native captures retain valid
required grade artifacts. No causal, complete billing or full tool timing claim
is made. Official release status remains false.

Source: DeepSWE, with its declared `swe-bench-ultra` lineage preserved. The
source-specific review and native verifier gates remain enabled. Source review
was delegated; it was not human review. Native-outcome pilot qualification does
not establish official passing calibration or a v1 release.
